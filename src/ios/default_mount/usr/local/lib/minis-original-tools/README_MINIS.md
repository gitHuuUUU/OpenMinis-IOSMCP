# Original technical resources

The six Python utilities and LICENSE in this directory are byte-for-byte
copies from the reviewed ordinary technical portion of the supplied archive.
47 original skills and their own scripts are bundled separately and imported
through the existing Skills store. Existing local-* mobile variants remain.

These are source references, not a claim that Windows paths, drivers, .NET,
Frida targets or all desktop dependencies are available on iOS. Original
source paths and text were deliberately preserved at the user's request.
Three original scripts (exact_scan.py, network_bypass.py, overlay_render.py)
have syntax errors and are preserved for inspection, not auto-run or silently
rewritten. Check platform, dependencies and side effects before using a script.
The download helper has unpinned downloads and invokes package installers;
it is not used by Minis' automatic installation/diagnostic path.

Model-governing override prompts, their deployment machinery, Git history,
bytecode caches and desktop tool binaries were not imported. See the source
manifest for exact included file hashes and exclusions. No script from this
directory is automatically executed on application startup.
